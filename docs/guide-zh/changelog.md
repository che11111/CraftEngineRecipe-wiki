## 1.0.17

- 增加 GitHub 正式版更新提醒，默认开启，可通过 `check-for-updates` 关闭。
- 增加合成器分类页，可按工作台、熔炉、高炉、烟熏炉、营火、切石机、锻造台和酿造台浏览配方。
- 增加主手查询、准星方块查询和操作说明按钮；准星查询可使用 `/cer target`。
- 支持 `/cer hand`、`/cer target` 查询原版及 CraftEngine 物品的制作配方。


## 1.0.16

- 主手与准星查询分别播放成功或失败声，不叠加普通点击、打开或关闭声。
- 分类栏或物品列表翻到边界、左键或右键物品没有可打开的配方时，复用 `sounds.query-failure`，每次只播放一次失败声。
- 修复 `UI_BUTTON_CLICK-1-2` 等带音量、音调参数的声音写法；统一使用 `sounds.open-menu`、`sounds.close-menu` 设置开关菜单声音。
- 修复翻页时叠加播放多个声音的问题，分类切换、物品翻页与返回可分别设置音效。
- 合成器分类页沿用分类栏布局，支持分页，并遵循权限与隐藏规则。
- 更新按钮图标、默认标题样式和配色，同步中英文文案。
- 旧 `config.yml` 和内置中英文语言文件自动补齐缺失配置，保留已有设置。
- 资源包语言读取与搜索索引构建改为后台处理，物品名称分批读取，减少加载时的集中处理。
- 支持按物品 ID、名称、翻译键、中文拼音和首字母搜索；读取资源包语言文件，补全翻译名称搜索。

## 1.0.14

- 增加 Folia 实验性支持，Folia 下禁用临时 OP 按钮动作。

## 1.0.8

- 分类支持自定义顺序、可见权限和隐藏规则；`hidden-items` 可用 `'*'` 隐藏分类内全部直接物品，`hidden-categories` 可连同分类按钮一起隐藏。
- 增加自定义按钮，支持声音、关闭菜单、延迟、玩家命令和控制台命令等动作。
- 增加中英文语言文件，可修改标题、按钮、悬浮说明与提示消息。
- 内置背景和按钮资源，首次启动自动安装到 CraftEngine；保留安装标记后，不会因资源目录改名而重复安装。本地副本只补缺，不覆盖已有文件。
